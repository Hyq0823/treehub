# 人格测试树

微信原生小程序。本地版以探索图鉴、个人树形、测评报告和历次记录组成完整流程，无需登录或后台服务。

## 开发与验证

使用微信开发者工具导入本目录，沿用 `project.config.json` 中的项目配置。大厅和「我的档案」为底部标签页。当前云机器没有微信开发者工具；原生布局、触摸反馈和设备存储仍需在工具与真机预览中检查。

无需 npm 安装。逻辑测试使用 Node.js 24（读取原有 ESM 题库）：

```sh
node --test tests/*.test.cjs
```

可选的 WXML/WXSS 编译检查使用官方编译器封装，安装在 checkout 之外，不改应用依赖：

```sh
npm install --prefix /tmp/treehub-compiler --no-audit --no-fund miniprogram-compiler@0.2.3
node -e "const c=require('/tmp/treehub-compiler/node_modules/miniprogram-compiler'); c.wxmlToJs(process.cwd()); c.wxssToJs(process.cwd()); console.log('WXML/WXSS passed')"
```

编译检查与 Node 页面控制器测试不替代微信真机测试。验证流程：首次进入 → 选卡 → 完成六套测试中的一项 → 已保存报告 → 我的档案 → 再测一次 → 对照两次历史报告 → 查看树的成长记录。还应确认退出重开后数据保留，以及清理存储后的首次进入状态。

## 第一版规则

- 完成 **不同测试** 的数量决定成长：1 初芽、3 扎根、5 舒展、10 繁茂、20 花冠、35 星辉；零项为待萌芽。现有六套测试仅提示可达到的下一阶段，其他阶段标为未来开放。
- 重复测评新建记录，不覆盖旧报告，不重复增加探索种类。每次记录附有树形快照。
- 报告分为基础版与 VIP 深度版。基础版直接查看；完整观看一次激励视频后，永久解锁当前这条测评记录的完整维度、优势盲区、关系模式和行动建议。复测生成的新记录需要独立解锁。
- 广告完整观看后先保留完成凭据，再保存报告权益。存储失败会显示“待保存”和重试入口；恢复空间或返回报告页时可直接补存，无需重看广告。凭据优先写入独立的小存储项；若设备完全无法写入，则在当前小程序进程内保留，需恢复存储后完成保存。
- 最近一次有效版本的 MBTI、内外向、九型和大五结果为六种树形提供匹配线索。SBTI、阴影人格仅作为趣味探索和成长记录，不参与树种推断。
- 六种树形是视觉意象，不是心理诊断，也不作性格优劣排序。匹配依据在档案中可见。
- 设备种子固定外观细节。新增结果可调整匹配树种；历史快照保留当时的形态与文案。
- 首批使用六种成熟树素材，萌芽/扎根用轻量矢量式样式绘制，后续阶段通过尺度和装饰区分。可后续替换为逐阶段专属素材。

## 数据与扩展

- `utils/archive.js`：单键 `personalityTreeArchive.v1` 保存版本化档案、设备种子、规范题号答案、分数、结果、日期与树形快照。写入失败保留页面答案；格式异常停止写入，不自动重置。旧版 `testResult` 仅迁移一次，并保留原键；旧版错误空分数不展示为新版有效报告。
- `utils/scoring.js`：评分版本 `2`，统一处理数字题号与 `qN`、九型单票计分、IE 外向计数、大五反向题及五维结果。
- `utils/deep-report.js`：按六套测试生成不同的深度维度与解读；`data/ads.js` 保存报告激励视频广告位 ID。
- `utils/premium-access.js`：记录已完成广告的待保存凭据，按测评记录补存权益；页面退出后停止广告加载与显示重试。
- `data/trees.js`：树种寓意、解读文案和成长阶段；`utils/personality-tree.js`：匹配规则及可追溯依据。
- `data/exploration.js`：大厅分类、卡片标题、探索引导。新增测试仍需在 `data/tests/index.js` 注册，并检查评分、版本和报告适配。
- `assets/stickers.png`：六套测试的透明纸贴插画，未探索时置灰并显示解锁标记。
- `components/personality-tree/`：树形展示；`assets/trees/species.png` 为首批生成后压缩的透明素材，3列×2行依次银杏、榕树、松树、枫树、柳树、橄榄树。新增树种时同步增加匹配规则、素材位置和组件配置。
- `pages/tree-history/`：每次测评的树形历史；不会用当前结果重算过去的快照。
- `packages/reports/`：报告页与 SBTI 结果图片所在分包，打开报告时由微信按需加载。应用内链接直接进入分包；旧的 `pages/test-result/index` 地址保留轻量跳转，继续支持已有报告链接与记录 ID。

测评和探索日志只保存在当前设备，不调用远程分析接口。换设备、删除小程序或清理数据后可能无法恢复；当前不提供云端同步。存储达到设备限制时提示保存失败，保留已有记录，不静默清理。

`app.json` 使用 `lazyCodeLoading: "requiredComponents"` 按需注入组件。`project.config.json` 已将设计参考图、文档和测试目录排除出小程序包，避免将约17MB设计图打包。包体检查分别计算主包与分包，主包源文件预算为 1.4 MB、每张运行图片预算为 200 KB，给微信编译产物留出余量。
