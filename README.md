# 人格测试树

微信原生小程序。面向喜欢自我探索与精致数字收藏的用户，提供六套测试、九套树与双伙伴主题、历史报告和自愿云备份。逐题原始答案仅留本机；云备份默认关闭。

## 开发与验证

使用微信开发者工具导入本目录，沿用 `project.config.json` 中的项目配置。底部标签页为「探索｜我的树｜档案」。当前云机器没有微信开发者工具，原生布局、广告、平台隐私授权与海报需在真机验收。

云环境 ID 为 `cloud1-d2ghbskq3663254ce`。按 [`cloudfunctions/README.md`](cloudfunctions/README.md) 配置数据库与云函数，再按 [`素材与发布.md`](docs/素材与发布.md) 上传仓库外的九套透明美术并填写真实 fileID。用户明确开启备份后才会同步，网络失败保留本机记录。

发布前执行 `node scripts/check-release.cjs`。未配置素材云 ID、真实运营主体及联系方式时，该检查有意失败；代码不会虚构已上传文件或已完成备案。产品、分享与搜一搜策略见 [`产品与微信搜一搜.md`](docs/产品与微信搜一搜.md)，数据与平台声明见 [`隐私声明与备案填写清单.md`](docs/隐私声明与备案填写清单.md)。

无需 npm 安装。逻辑测试使用 Node.js 24（读取原有 ESM 题库）：

```sh
node --test tests/*.test.cjs
```

可选的 WXML/WXSS 编译检查使用官方编译器封装，安装在 checkout 之外，不改应用依赖：

```sh
npm install --prefix /tmp/treehub-compiler --no-audit --no-fund miniprogram-compiler@0.2.3
node -e "const c=require('/tmp/treehub-compiler/node_modules/miniprogram-compiler'); c.wxmlToJs(process.cwd()); c.wxssToJs(process.cwd()); console.log('WXML/WXSS passed')"
```

手机 UI 辅助预览与三档宽度验收见 [docs/UI还原与验收.md](docs/UI还原与验收.md)。

编译检查与 Node 页面控制器测试不替代微信真机测试。验证流程：首次进入 → 选卡 → 完成六套测试中的一项 → 已保存报告 → 我的档案 → 再测一次 → 对照两次历史报告 → 查看树的成长记录。还应确认退出重开后数据保留，以及清理存储后的首次进入状态。

## 视觉与交互

- 整体采用清透浅蓝、奶油白和精致 3D 伙伴主题，大厅、答题、报告与个人树保持一致。
- 「我的树」独立展示九主题图鉴、两位互动伙伴、成长记录与海报。极光水镜未发现时只展示剪影，不提前请求完整美术。
- 答题页展示实时进度、已记录数量和选择确认反馈；题目切换、选项选中、能量扫描和加载状态均带有轻量动效。
- 深度报告使用蓝色图表、三屏解读和行动卡，便于截图；主题海报由用户主动生成，临时预览不主动申请相册写入权限。
- 动效只使用微信小程序 WXSS 动画，不依赖第三方组件；最终节奏、长文本换行和低端机表现以开发者工具和真机预览为准。

## 产品规则

- 首次有效测评可免费选择「柔软的冒险家」或「慢热的浪漫家」之一；普通主题完整看一次视频解锁当前主题，极光水镜需先探索五类不同测试再视频解锁。主题与报告权益分别保存，不相互代替。两台设备各自选择的合法基础主题可在备份时合并。
- 主题只是视觉意象，结果提供推荐，已拥有主题可以切换，不将用户永久绑定标签。分享只带公开主题或测试 ID，不带私人结果记录。
- 完成 **不同测试** 的数量决定成长：1 初芽、2 双叶、3 扎根、4 新枝、5 舒展、10 繁茂、20 花冠、35 星辉；零项为待萌芽。前五项测试每完成一项都有新的视觉阶段，现有六套测试仅提示可达到的下一阶段，其他阶段标为未来开放。
- 重复测评新建记录，不覆盖旧报告，不重复增加探索种类。每次记录附有树形快照。
- 报告分为基础版与 VIP 深度版。基础版直接查看；完整观看一次激励视频后，永久解锁当前这条测评记录的完整维度、优势盲区、关系模式和行动建议。复测生成的新记录需要独立解锁。
- 广告完整观看后先保留完成凭据，再保存报告权益。存储失败会显示“待保存”和重试入口；恢复空间或返回报告页时可直接补存，无需重看广告。凭据优先写入独立的小存储项；若设备完全无法写入，则在当前小程序进程内保留，需恢复存储后完成保存。
- 最近一次有效版本的 MBTI、内外向、九型和大五结果为六种树形提供匹配线索。SBTI、阴影人格仅作为趣味探索和成长记录，不参与树种推断。
- 六种树形是视觉意象，不是心理诊断，也不作性格优劣排序。匹配依据在档案中可见。
- 设备种子固定外观细节。新增结果可调整匹配树种；历史快照保留当时的形态与文案。
- 首批使用六种成熟树素材；初芽、双叶、扎根、新枝使用独立的透明成长精灵图，每次新探索增加一枚金色成长印记。后续阶段通过尺度和装饰区分。

## 数据与扩展

- `utils/archive.js`：单键 `personalityTreeArchive.v1` 保存版本化档案、设备种子、规范题号答案、分数、结果、日期与树形快照。写入失败保留页面答案；格式异常停止写入，不自动重置。旧版 `testResult` 仅迁移一次，并保留原键；旧版错误空分数不展示为新版有效报告。
- `utils/privacy.js` 与 `pages/privacy/`：政策版本、单独备份选择、微信平台隐私授权、关闭备份、导出及删除。拒绝备份不影响本地测评。
- `utils/cloud-sync.js`：仅在明确同意后上传结果摘要与主题权益；不上传 answers 或 treeSnapshot。历史本机快照保留，新设备用摘要还原并标明成长意象。
- `cloudfunctions/treehub-api`：OpenID 隔离、授权版本、白名单、事务写入与防止删除后旧请求重传的撤回标记；客户端禁止直接访问数据库。
- `data/themes.js`、`utils/themes.js`、`utils/rewarded-video.js`：九主题、推荐、权益、完整视频收据与离页取消。报告与主题使用独立的存储键和完成回调。
- `utils/theme-assets.js`、`config/theme-assets.js`：按需解析云文件；九套新美术不进入应用包。管理端上传与配置导入脚本在 `scripts/`，不随小程序发布。
- `utils/scoring.js`：评分版本 `2`，统一处理数字题号与 `qN`、九型单票计分、IE 外向计数、大五反向题及五维结果。
- `packages/reports/deep-report.js`：按六套测试生成不同的深度维度与解读；同目录的 `ads.js` 保存报告激励视频广告位 ID。
- VIP 报告拆为“画像图表、深度解读、行动卡”三屏；画像页使用倾向清晰度雷达图或单维光谱，并组合本次人格树，方便手机截图保存。
- `packages/reports/premium-access.js`：记录已完成广告的待保存凭据，按测评记录补存权益；页面退出后停止广告加载与显示重试。
- `data/trees.js`：树种寓意、解读文案和成长阶段；`utils/personality-tree.js`：匹配规则及可追溯依据。
- `data/exploration.js`：大厅分类、卡片标题、探索引导。新增测试仍需在 `data/tests/index.js` 注册，并检查评分、版本和报告适配。
- 既有 `assets/trees/` 与报告分包中的旧结果图片保留历史兼容；新九主题美术完全从云开发空间加载。
- `components/personality-tree/`：树形展示；`assets/trees/species.png` 为成熟树透明素材，3列×2行依次银杏、榕树、松树、枫树、柳树、橄榄树；`assets/trees/growth.png` 为前四个成长阶段的 2列×2行透明素材。新增树种或阶段时同步增加匹配规则、素材位置和组件配置。
- `pages/tree-history/`：每次测评的树形历史；不会用当前结果重算过去的快照。
- `packages/reports/`：报告页与 SBTI 结果图片所在分包，打开报告时由微信按需加载。应用内链接直接进入分包；旧的 `pages/test-result/index` 地址保留轻量跳转，继续支持已有报告链接与记录 ID。

默认只有本机档案。用户分别同意政策、微信平台指引并开启云备份后，才关联当前微信账号保存结果摘要、版本、时间、树种子和权益。原始逐题选项不上传，不向第三方分析服务发送分数或结果。关闭备份停止同步；已有云数据可单独删除；失败的删除保留重试入口。

`app.json` 使用 `lazyCodeLoading: "requiredComponents"` 按需注入组件。`project.config.json` 将云函数目录单独配置，并把文档和测试目录排除出小程序包。包体检查分别计算主包与分包，主包源文件预算为 1.4 MB、每张运行图片预算为 200 KB，给微信编译产物留出余量。
