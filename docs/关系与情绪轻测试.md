# 关系与情绪轻测试

新增三套轻测试，沿用现有逐题选择、自动切题、结果揭晓、多维图表、深度报告和历史记录，不新增表单或权限。

| 测试 | ID | 题数 | 观察方向 |
| --- | --- | --- | --- |
| 亲密相处节奏 | `relationshiprhythm` | 12 | 联系、表达、独处空间与分歧后的回应 |
| 温柔边界测试 | `gentleboundaries` | 12 | 感受觉察、需要表达、恢复方式与边界一致性 |
| 情绪充电地图 | `emotionalrecharge` | 10 | 安静、连接、活动、感官与秩序带来的恢复偏好 |

这些结果描述本次生活自评，不用于诊断依恋类型、判断关系好坏或预测心理健康。偏好之间没有优劣，用户可以在近期生活变化后复测，结合当时情境观察差异。

## 产品接入

大厅新增“关系”分类，亲密相处与边界测试归入其中；情绪充电归入“情绪”。完成新测试计入不同探索数量与既有主题条件，复测保留新记录但不重复增加探索等级。结果为树形提供不同的趣味视觉意象，已有历史快照不重写。

题库、轻量目录和结果标题同步维护，大厅首屏不加载完整题库。逐题原始答案继续留在本机；云备份复用已有摘要格式，不增加新集合或额外个人资料。

基础报告展示完整四／五维图表；深度解读与行动建议继续按单条记录看视频解锁。报告下方优先推荐两项相关且尚未探索的测试，点击后使用页面替换直接作答，沿用普通记录，不反复叠加详情页。已全部探索时仍允许选择复测。推荐只读取已完成的测试 ID，不上传分数或逐题答案。

## 扩容与性能

详情、答题、报告与档案校验统一通过 `data/test-loader.js` 的静态加载表按 ID 读取题库。全量入口只供开发测试，已排除出小程序包；新增测试需同步加载表，并运行 `tests/test-loader-performance.test.cjs`。页面传给 `setData` 的仍是当前题目或报告摘要，不传全题库。

报告主题准备复用已读取的历史快照，减少两次全档案读取／克隆；推荐卡使用轻量元数据且不额外请求素材。图片继续仅对可见卡片按批次解析远端地址。

本云机器的五次新进程对照中，全量 13 套／238 题初始化中位数为 32.31ms，单套相处节奏／12 题为 7.51ms。这是 Node 开发对比，不代表微信启动耗时。主包源码估算约 685KB，报告分包约 424KB，均在现有预算内；微信编译后的实际体积和真机启动数据以开发者工具、体验版及线上性能后台为准。

## 发布时的云端步骤

代码拉取后，在微信开发者工具中右键 `cloudfunctions/treehub-api`，选择“上传并部署：云端安装依赖”。这次部署会把三套新测试 ID 加入探索计数白名单，使跨设备恢复与主题解锁保持一致。

三套测试使用现有 CSS 图形、文字与已有云主题素材，无需新增上传图片，也无需修改 `public` 目录或存储权限。业务素材仍全部走远端，代码包不放新增测试图片。将来需要插画时统一上传到 `public/v2/tests/<test-id>/`，上传完成后再配置 `assetPath`。
