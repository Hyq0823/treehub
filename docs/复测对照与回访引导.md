# 复测对照与回访引导

本轮保留现有十五套测试，把「回来继续 → 再次记录 → 看见变化 → 收藏年轮」接成一个闭环。不增加每日任务、连续打卡或订阅提醒。

## 首页接回上次的探索

首页在同一个紧凑区域展示下一步：有有效本机进度时，先邀请继续；没有进度时，用户可选择关系相处、情绪充电、生活方向或轻松探索，看到一项相应测试。

引导优先推荐尚未完成的测试；一个方向都已探索时，邀请回看最久未记录的一面。重新记录先进入详情，由用户选择本次状态；不直接复用过去的私人事件，也不自动提交答案。

首页只使用已读档案中的测试 ID、时间和有效性，以及一次本机草稿摘要读取。不为推荐请求云端，不从分数推断用户心情，不加载完整题库；草稿答案、题序和私人状态不传给首页视图。

`data/draft-manifest.js` 是开发脚本生成的少量版本、签名和题目形状元数据，不包含题目文本。新增或修改题库后运行：

```sh
node scripts/update-draft-manifest.cjs
node scripts/update-draft-manifest.cjs --check
```

`check-release.cjs` 会只读检查它是否过期，防止旧题面进度被错误引导为可继续。完整恢复仍由详情和答题页校验。

## 两次的我

同版本复测后，可从报告、档案和成长年轮进入「两次的我」。页面展示两次日期、结果意象和成对维度条；可按每批五条选择更早的同版本记录。

显式记录链接找不到时给出说明，不自动换成其他记录。旧版导入、不同评分版本、不同题库版本、无法解读的摘要不参与比较；保留版本的历史题库仍可在其自身版本内对照。

配置式轻测试直接显示完整免费维度。经典测试先展示既有基础对比，完整维度沿用当前报告的解锁范围，不能通过对照页绕过当前记录的权益校验。完整观看视频后尚待保存的当前记录凭据也继续有效，并提示返回报告补存，无需重看。历史报告、树形快照和已保存权益均不改写。

从对照页回看报告时，目标正是上一页的同一记录则直接返回，避免重复堆叠页面。原报告返回及准备播放视频前会复核当前记录的权益；其他报告已解锁同一记录时立即更新，不再次要求观看。首次进入继续复用已读取的权益状态。

差值使用「百分点」：例如 30% 到 40% 是 +10 个百分点，不是能力提升 10%。图示位置取整，细小差异不能解释为人格变好或变差。九型对照使用固定题数下的选择占比，避免各次最高票不同造成虚假的维度移动；单次报告的相对雷达图口径保持不变。

## 年轮收藏卡

用户主动点击后，才将两次结果、日期和当前可查看的维度绘成 750 × 1000、3:4 的临时收藏图。原生年轮图形和成对条形图无需下载图片；一维到九维均有独立布局，六至九维使用紧凑三列避免重叠。

卡片不包含私人事件、原始选项、记录 ID 或账号标识；微信聊天邀请仅带公开测试 ID，并使用既有 5:4 封面，竖版图通过图片预览菜单保存。切换历史基准或离开页面后，迟到绘图不会打开预览或覆盖另一份卡片。

## 性能与验收

档案首页只增加一个可比较的记录 ID；示例 4,000 条复测的首屏 `groups` 约 358 B，历史展开五条约 1 KB。该数值是 Node 合成数据的界面传输量，不代表微信真机耗时，可用 `node scripts/benchmark-archive.cjs 4000` 重现。

对照页与绘图模块在现有报告分包内，不增加首包图片、音频、独立测试页面或云端数据收集。搜索范围继续只允许公开探索和详情页，对照页不收录。

发布前依照 README 运行回归、依赖/媒体检查与 WXML/WXSS 编译；真机重点验收未完成进度回访、同版本基准切换、经典报告解锁一致性、九维收藏图、切后台后的取消和失败重试。本轮没有云函数接口变化。
