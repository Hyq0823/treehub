# 埋点事件字典 + 后台配置步骤

> 目的：跑通站外切片实验的最后一环——**"有没有人真的从小红书搜进来测了"**，以及分享链路的真实转化率。
> 代码已就位（`utils/track.js` + 5 个页面接入），**不做任何用户身份识别、不存任何个人信息**，因此不需要隐私弹窗，不引入云开发。

---

## 一、你需要在微信后台做的一步（5 分钟，只能你登录做）

小程序后台 → **统计 → 自定义分析 → 新增事件**，逐个建下面 8 个事件，**事件值参数名统一填 `enterScene`、`testId`**（`resultType` 只在两个事件里需要）。

| eventId | 事件名（后台显示用） | 参数 |
|---|---|---|
| `hall_view` | 大厅曝光 | enterScene |
| `detail_view` | 测试详情曝光 | enterScene, testId |
| `test_start` | 开始答题 | enterScene, testId |
| `test_abort` | 答题中途放弃 | testId, reachedIndex, totalCount |
| `test_submit` | 完成答题 | testId, resultType, unanswered |
| `result_view` | 看自己的报告 | testId, resultType |
| `result_view_foreign` | 看别人的报告（分享落地） | testId |
| `share_tap` | 点击分享 | testId, resultType |

**没配置会怎样**：`wx.reportEvent` 静默失败，不影响任何业务；同时每次上报都会写一份到本地缓存 `trackLog`（保留最近 300 条），开发版里能直接看到，所以**实验不会因为后台没配就白跑**。

---

## 二、跑通后要看的四个数

1. **完成率** = `test_submit` ÷ `test_start`，分测试看
   → 直接决定搜一搜排名（使用时长和完成率是权重因子）。哪套完成率最低就先改哪套。
2. **放弃位置** = `test_abort` 的 `reachedIndex` 分布
   → 如果大量人在第 12 题放弃，说明题太长，不是内容问题。这是唯一能定位"该砍题还是该换题"的数据。
3. **分享率** = `share_tap` ÷ `result_view`
   → 飞轮的第一圈。低于 5% 说明结果页没有社交货币属性。
4. **分享落地转化** = `result_view_foreign` ÷ `share_tap`
   → **这个数字现在几乎一定是 0 或极低**，因为朋友圈单页模式会把人导向空白页。它就是你修分享链路的收益凭证。

另外用 `enterScene` 分组看来源构成：

| scene | 含义 | 关心它是因为 |
|---|---|---|
| 1007 / 1008 | 聊天转发（单人/群） | 飞轮是否在转 |
| 1154 | **朋友圈单页模式** | 出现即等于"有人点开但看到空白" |
| 1027 / 1023 / 1006 | 搜索（搜一搜/输入框/发现） | 小红书简介导流的真实效果 |
| 1035 / 1036 | 公众号菜单 / 文章 | 以后做公众号时才有量 |
| 1089 / 1017 | 我的小程序 / 历史列表 | **复访率**，粘性的唯一硬指标 |

**实验成功的判据**：发小红书那一周，搜索类 scene 的进入量相对前一周有可见增长。这就是"站外内容 → 微信内被搜到"这条链路是否成立的直接证据，不需要任何归因猜测。

## 三、这轮没做的事（按你的决策往后放了）

- **反馈入口仍是"开发中"**（`pages/user-center/index.js`）。它是差评止损最便宜的口子，建议下一轮补：本地提交 + 你的邮箱/企微引导。
- **分享链路 bug 未修**（`result_view_foreign` 现在会把人送去答题页 / 空白页）。**故意不在这轮修**——先让它产生一周真实数据，你才看得到漏得多厉害，修完才有对照。修的时候按规划文档第九章 9.5 的方案（无结果时渲染"类型图鉴页"，兼容单页模式）。
- **SBTI 图片仍在主包**（1.3MB）。性能按前面判断排第三优先，等完成率数据出来再决定优化哪一段。

## 四、身份隔离（实验前置，注册账号之前定）

- 用与工作无关的昵称、头像；不出现真实姓名、工牌、办公场所、公司相关内容。
- 建议独立手机号注册，微信与小红书都不用主号登录。
- 内容边界：只发人格测试/心理测评题材，不发任何与中国移动、同事、内部流程有关的东西，不发办公室照片。
- 小程序名与账号名不必一致（不一致反而更难被关联），但**简介里要写清小程序名**，否则"怎么测"的评论没法承接。
