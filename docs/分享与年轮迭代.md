# 分享与年轮迭代

本轮把十三套扩展为十四套测试，新增「你的城市生活气质」，并补齐主题收藏、个人分享与回访入口。没有新增打包图片、音频、第三方组件或个人资料收集。

## 用户体验

- 首测根据结果生成并免费领取一套主题。其余基础主题也有可达到的探索条件：柔软的冒险家在六类、慢热的浪漫家在七类、安静的观察者在八类不同测试后获得；已拥有主题不回收，也不改变原获取记录。复测不重复增加探索种类。
- 首页展示最近有效记录的结果、日期与本机状态；同一测试、题库版本和评分版本的重复记录显示年轮。复测入口重新进入详情页，仍默认普通记录，不自动沿用过去的分手、工作变化等标签。跨版本不直接比较，云摘要缺失的状态不补写。
- 普通报告增加主动制作的结果卡。点击后才加载报告分包里的绘图模块，生成 500×400 的 5:4 聊天分享图；内容为身份名称、共鸣短句、免费维度图与树。生成后可以预览并通过微信预览界面保存，也可以分享到聊天。临时文件属于用户主动制作的个人卡，不是应用自带业务素材。
- 卡片只使用已解析的远端主题图；不触发额外素材解析请求。无图、图片错误或超时时仍以原生简洁树形绘制。缓存与记录、主题及图片地址绑定，切换内容或离开页面时迟到结果不能覆盖当前卡片。广告权益不参与分享卡缓存和内容选择。
- 新测试为十题、五维、四种城市生活意象：都市漫游者、海风慢生活者、街巷收藏家、山野栖居者。它描述生活偏好，不获取定位、收入或住址，不作为求职、搬家或城市适配结论。

## 云端兼容与发布

先在微信开发者工具中上传并部署 `cloudfunctions/treehub-api`，选择云端安装依赖，再上传客户端体验版。此次云函数加入城市测试白名单、六／七／八类主题条件及对应分页校验。无需上传新素材，也无需调整云存储权限。

客户端同步携带 `themeRulesVersion: 2`。服务端保留主题获取记录的实际来源；对已发布旧客户端的响应，仅将基础主题的新探索来源表示为旧版能读取的基础主题来源。旧客户端再次同步不会把服务端原获取来源覆盖掉。原隐私授权与用户隔离规则保持，逐题答案仍不上传。

真机验收重点：跳过首测领取后可回报告领取、主题进度与实际条件一致、最近记录能回看且复测默认普通记录、制作卡片不阻塞报告首屏、图片失败仍能成卡、分享图完整显示且路径不包含私密记录 ID。原生 Canvas 与微信分享最终效果以体验版真机为准。
