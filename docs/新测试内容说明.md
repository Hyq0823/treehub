## 内容定位

古人测试使用文学与公众文化意象提供共鸣，不声称了解历史人物的真实人格，也不把用户性格与人生结局联系起来。六种结果分别借用李清照、苏轼、王阳明、李白、徐霞客、陶渊明的文化意象。性别不影响匹配，题目不收集用户性别。

生活路径测试提供轨道筑梦者、旷野漫游者、双栖探索家、自由建造师四种组合。规律、自由、自主和陪伴都是可以被承认的需要；任何结果都不建议用户直接离职、搬家或进行重大投入。

隐藏天赋测试中的“天赋”是入口的趣味表达，实际观察的是用户愿意投入的活动方向，不是能力测验、智力测验或职业推荐。每个结果都通过小实践鼓励用户验证兴趣，而不是给能力定级。

## 题目和结果规则

每道题只有一个观察维度，四个选项对应 1–4 分。选项顺序在题间交错，不以选项字母或题目位置直接决定结果。古人和生活路径每个维度三题，隐藏天赋每个维度两题。

维度位置由本维度可取得的最低、最高原始分归一化得到，不是人群百分位、准确率或能力高低。结果由完整维度组合与配置中的文化/偏好原型相对接近程度决定。每个结果均可由合法作答得到；重复答题可能随近期状态变化。

每个结果都包含一条可分享的短句、基础解释、提醒、优势线索、可能忽略的事、关系中的应用和三条小行动。无论基础或深度报告，都应保留对应测试的内容说明，不把原型距离包装成“相似度百分比”。

## 素材和扩展

本轮不添加本地业务图片，也不配置尚未上传的云端素材路径。视觉由现有页面的 CSS 与字符图形呈现。未来如增加插画，沿用 `public/v2/tests/<test-id>/` 云目录和 `assetPath` 配置；不得添加本地图片兜底。

新增同类轻测试时，可复用 `createProfileTest` 配置：维度定义、等量情境题、原型向量、独立结果文案。每次新增后需确认所有结果均可达，并核对轻目录、探索进度、报告和树成长映射。
