# 友情里的你

新增第十五套测试：12 题、4 个生活偏好维度，约 3 分钟。通过周末见面、一起尝试新事、朋友低落时的陪伴、异地小约定等场景，呈现一份可收藏的友情配方。

| 维度 | 两端偏好 |
| --- | --- |
| 相聚场景 | 一对一相聚 ↔ 小群体相聚 |
| 共同体验 | 熟悉的小据点 ↔ 新鲜的共同体验 |
| 陪伴方式 | 先陪着听一听 ↔ 一起想想办法 |
| 维系习惯 | 随心自然续上 ↔ 约定的小仪式 |

五种结果为「友情小客厅」「出走搭子」「并肩行动派」「相聚发起人」「自在老友」。结果是此次自评与原创意象的匹配，不评判友情质量、受欢迎程度或朋友是否值得交往；面对不同朋友可以有不同答案。

基础版直接提供完整四维图表、结果短句和建议，可制作横版聊天卡与 3:4 收藏长图。深度报告沿用当前记录的视频解锁规则，增加陪伴方式、容易忽略的需要与三步行动建议。没有双人邀请门槛，也不会收集朋友的信息。

## 接入与性能

沿用 `createProfileTest`、通用详情/答题/报告、草稿、年轮和结果卡。题库仅选中当前 ID 时加载；大厅、档案与树形使用轻量元数据。不新增专属页面、云集合或原始答案收集。

大厅复用已存在的远端 `listener` 主题，未配置尚不存在的插图路径，代码包没有新增图片、音频或图片 ZIP。未来有独立插画时，按 [新测试接入与云素材](新测试接入与云素材.md) 上传版本化云路径后再配置。

从亲密相处节奏的相关探索可进入友情测试，友情结果再连接情绪充电和温柔边界。中途有本机进度时先进入详情选择继续；普通新测保持普通记录默认值。

## 发布顺序

1. 将 `cloudfunctions/treehub-api` 部署到现有云环境，新增 `friendshipstyle` 测试白名单，同时保留此前主题规则兼容逻辑。
2. 使用微信体验版验证友情测试完成、复测、四维图表、断点续答、两种结果卡和当前记录广告解锁。
3. 确认新测试的结果摘要能云备份后，再提交客户端审核。旧版客户端和历史题库不需要迁移。

客户端和 Node 回归通过不表示云函数已经部署；开发环境没有云账号凭据，不替用户执行云端发布。

- 内容标题：**原来友情也有自己的节奏，我测到了「自在老友」**
- 配图正文：**12 个日常小场景，看看你更喜欢怎样相聚、陪伴和保持联系。没有更好的类型，只收藏这一次的自己。**
- 自然关键词：友情测试、朋友相处、陪伴方式、友情配方。标题与实际结果保持一致，不使用“鉴定真假朋友”“测出谁不爱你”等文案。
