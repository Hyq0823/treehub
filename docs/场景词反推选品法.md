# 场景词反推选品法 · 工作表

> 适用：小红书母婴**第一档工具**（不入口、不贴身、非玩具、非护肤）无货源/分销选品。
> 核心规则：**先定词，再定品。** 顺序反了就会掉回"这个也便宜、那个也好上"的贴纸老路。
> 建立日期：2026-10-12。

---

## 零、为什么顺序不能反

贴纸那轮的失败不是选品失败，是**内容打不到掏钱的人**。根因是品类词没有意图：搜"可爱贴纸"的人不急着要任何东西。

榜单上出单的笔记全是同一个结构：**症状 → 解药**。搜"半夜痒醒"的人，今晚就要解决。

所以词的价值只有一个衡量标准：**它背后的人，是不是正处在某个具体的麻烦里。**

## 一、第一档工具白名单（判定门槛，先背下来）

看词之前先记住能做什么，否则捞到的词一大半会落到不能碰的品上。

### 可以做（无强制认证）

| 场景域 | 具体品 |
|---|---|
| 清洗刷具 | 奶瓶刷、奶嘴刷、**吸管刷**、**杯口刷**、保温杯刷、长柄海绵刷 |
| 晾晒收纳 | 奶瓶**沥水架**、晾干网兜、尿布台收纳盒、湿巾盒、衣柜分层挂袋 |
| 夹取工具 | 奶瓶夹、防烫夹、食物夹、冰格夹、辅食分装勺（不入口接触热食的前提下） |
| 居室整理 | 推车挂钩、床边收纳挂袋、玩具收纳筐、门后挂袋、抽屉分隔 |
| 护理周边 | **电动磨甲器**、婴儿指甲剪套装、**吸鼻器**、棉签收纳盒、理发围布、防水耳贴 |
| 清洁耗材工具 | 尿布桶、湿巾加热器（注意需 3C，见排除）、玩具清洁刷、缝隙刷 |
| 出行工具 | 安全座椅收纳袋、推车防脏垫、便携尿布垫（纺织类需 GB 31701，降级为谨慎） |

### 必须排除（碰了就等于回到化妆品那个坑）

| 排除项 | 原因 |
|---|---|
| 牙胶、摇铃、布书、安抚奶嘴、任何"能玩的" | **玩具类 3C 强制认证** |
| 碗、勺、水杯、辅食剪、研磨碗、硅胶围兜、分装盒 | **GB 4806 食品接触材料**，要检测报告 |
| 汗巾、床品、贴身衣物、爬行垫 | GB 31701 婴幼儿纺织 A 类，要吊牌标识 |
| 紫草膏、炉甘石、润肤霜、护臀膏、任何"涂在身上的" | 化妆品备案 + 小金盾 |
| 消毒液、抗菌喷雾、湿巾（含杀菌宣称） | 消字号 |
| 电器类（消毒柜、温奶器、加热器、理发器本体） | 小家电 3C + 售后重 |
| 任何"入口"的东西 | 一律不做 |

**判定口诀：不入口、不贴身、能玩的不做、要插电的不做、往身上抹的不做。**

## 二、第一步：把词捞出来（按这个顺序做，成本从低到高）

### 来源 A：拆上榜笔记的标题（**先做这个，你已经有数据了**）

你手上那张千帆「市场 → 笔记排行 → 阅读榜」就是词库。上榜 = 已验证能出单。把标题拆成词，只留下面这些槽位：

| 槽位 | 说明 | 从你截图里能直接看到的例子 |
|---|---|---|
| **时间/状态** | 什么时候最难受 | 「半夜」「夜醒」「终于结束了」 |
| **体感动词** | 身体的反应 | 「痒」「醒」「抓」「焐」「干」「皴」 |
| **情绪词** | 大人的状态 | 「疼」「崩溃」「不敢」「不当回事」「后悔」 |
| **转折/结果** | 认知被推翻 | 「别不当回事」「原来还有膏体」「牛」 |
| **对象限定** | 谁/什么部位 | 「宝宝」「小嘴」「脸」「屁」 |

**动作**：把「阅读榜」和「成交榜」各翻 3 页，抄 40 篇标题，按上面 5 个槽位拆词，去重后填进第三节表格。这一步纯手工，约 1 小时，零成本。

### 来源 B：搜索框联想词（免费，最真实）

小红书 App 搜索框输入"宝宝""新生儿""奶瓶""带娃"，把**下拉联想**逐条抄下来。联想词是平台按真实搜索量排的，比任何工具都准。

再补一层：输入"宝宝 半夜""宝宝 不""奶瓶 里""每次 都"这种**半截句**，联想会吐出大量带情绪的原话。

### 来源 C：「大家都在搜」+ 搜索结果页顶部相关搜索

搜完一个词，结果页顶部/底部的相关搜索词，继续抄。

### 来源 D：同行爆文的评论区（**含金量最高**）

在来源 A 挑出的爆文下面翻评论，重点看三类：
- 提问型："那 XX 怎么办" ← 这就是没人接住的需求
- 诉苦型："我家也是，每次…" ← 情绪原话，直接可当标题
- 补充型："还有 XX 也这样" ← 相邻需求，可扩 SKU

### 来源 E：千帆后台（数据有限，别指望太多）

- 「搜索 → 引流搜索词」：你店铺历史引流词。**注意：你近 30 天销量为 0，这里大概率是空的或极少，不要因此判断"没需求"，这是数据缺失不是结论。**
- 「市场 → 类目分析 / 实时商品 / 同品总览」：看同行什么在跑，用来验证 A~D 捞到的词有没有商业承接。

**情绪强度判定（严格按这个打，别手松）**
- **高**：今晚就会搜。带"半夜/哭/睡不着/出血/不敢/吓死"。
- **中**：这周会处理。带"烦/累/每次/怎么办/麻烦"。
- **低**：闲逛时看到才想起。**直接淘汰，不管商品多好卖。**

**硬性淘汰规则**（任一命中就划掉，不许犹豫）
1. 只能靠入口类/玩具类/护肤类接住的 → 淘汰
2. 需要宣称疗效才能卖动的（"治湿疹""防过敏"）→ 淘汰
3. 情绪强度为低 → 淘汰
4. 单品客单 < ¥15 且凑不成套装 → 淘汰

## 五、第四步：挑 3 个词开跑（打分模型）

| 维度 | 权重 | 打分依据 |
|---|---|---|
| 情绪强度 | 35% | 高=5，中=3 |
| 搜索热度 | 25% | 联想词排位越前越高 |
| 竞争密度 | 20% | 搜这个词，前 20 条里爆文越少分越高 |
| 客单可组合 | 20% | 能凑 ¥39+ 套装=5，单品 ¥19=2 |

**只跑总分前 3 名。** 不要一次铺 10 个词——你会在 8 篇笔记里换 8 个方向，等于没有测试。

## 六、标题公式（照抄结构，换你的词）

从榜单标题里能提炼出三种，都极短：

1. **状态 + 转折 + 小东西**
   「半夜痒醒的日子终于结束了」→ 你的版本：「奶瓶刷第 3 周就长黑点，换了这套才停」
2. **别不当回事 + 九个容易…**（清单式，天然适合套装）
   → 「起夜换尿布，九个动作顺序别搞错」
3. **本人用过 + 牛**（第一人称背书，不需要孩子出镜）
   → 「用过的吸管刷里，只有这把能插进保温杯盖缝」

**三条通用要求**
- 标题里出现**具体时间/数量**（第 3 周、九个、只有这把），比形容词有效
- 用**体感词**不用**病名**：写"痒醒、抓、睡不踏实"，不写"湿疹、皮炎"
- 前 12 字必须把场景说完，搜索页只显示这么长

## 七、合规红线词表

### 绝对不能出现在**商品标题 / 详情页 / 主图**

治疗、根治、药用、医用、消炎、杀菌、抗菌、抑菌、抗病毒、止痒、退红、消肿、防过敏、抗敏、提高免疫力、促进发育、开发智力、助眠、医院同款、儿科推荐

### 绝对化用语（全类目禁用）

最、第一、顶级、国家级、100%、纯天然、无副作用、零添加、永久

### 笔记正文的边界（重要，很多人搞混）

| 位置 | 性质 | 尺度 |
|---|---|---|
| 商品标题/详情 | **商业宣称**，你是责任人 | 上面所有词一个都不能出现 |
| 笔记标题 | 系统会做医疗宣称识别 | **不要出现病名**，用体感词 |
| 笔记正文（个人体验口吻） | 内容，不是宣称 | 可以写"娃挠到出血""看着红了一片"，但**不要写"用了三天湿疹好了"** |
| 评论区回复 | 同样算你的宣称 | 别在这里说疗效，这是最多人翻车的地方 |

**一句话：描述你的处境可以，描述产品的功效不行。**

## 八、第五步：14 天验证（只看一个数）

| 天 | 动作 |
|---|---|
| D1 | 来源 A：拆 40 篇上榜标题，填第三节词表 |
| D2 | 来源 B/C：搜索框联想词 + 相关搜索，补词表到 30 条 |
| D3 | 按硬性规则淘汰，按第五节打分，定 3 个词 |
| D4 | 每个词回第一节查白名单，确认工具能接住；确认不撞电器/入口/宣称 |
| D5 | 选品中心挂分销商品，**一件货不囤** |
| D6~D19 | 发 8 篇笔记，3 个词各 2~3 篇 |
| D20 | 看结果 |

### 判据（提前定死，不许事后改）

| 结果 | 结论 | 下一步 |
|---|---|---|
| 有 ≥1 篇进 1000+ 阅读**且**产生商品点击 | 内容能拿到分发 | 放大：同结构再铺 20 篇，测套装 |
| 有阅读但零点击 | 词对了，商品/价格不对 | 只换品，不换词 |
| 8 篇全部 < 300 阅读 | **账号已被做废**（54 篇低质铺量的后果） | 另起新号，别再救这个 |
| 8 篇阅读正常但零互动 | 词是假的，你在自嗨 | 回到 D1 重做，检查是不是把品类词当成了场景词 |

**第三种结果最疼，但它就是你要花两周换的那个答案。**

## 九、三条不要做

1. **不要先选品。** 打开 1688 逛一圈再回来想卖什么 = 顺序反了，必然重演贴纸。
2. **不要囤货。** 这一轮唯一要生产的资产是笔记。分销跑通了再谈压货。
3. **不要同时跑两个账号。** 小程序那边的内容线本季度暂停，只做不供稿的三件事（关键词卡位、修分享链路、配埋点）。
