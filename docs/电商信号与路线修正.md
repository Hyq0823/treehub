**"人格测试"这个需求，正在被人用真金白银在微信之外被满足。**

### 三个结论

**结论 1：¥1.98 买的是"我不知道去哪找"，不是测试。**
有店铺在把免费的官方测试转卖，而且卖爆了。这说明这个品类的核心痛点是**路径**，不是内容质量。

→ 对你的意义：**你已经拥有他们卖的那个东西，而且你比他们强**——微信小程序在微信内、零跳转、免费、不用等客服发货。
→ 但你没被搜到，他们卖了 5 万单。**差距 100% 在分发，0% 在产品。**

**结论 2：标题就是需求词表，这是免费的。**
"MBTI16型人格""官方正版""免费测试""专业版""最新版""理想型""情侣匹配""性格测试""城市适配"——这些是被真实付费验证过的搜索词。淘宝和微信搜一搜是同一批人、同一批词。

→ **这是这张图最值钱、且零成本的部分。** 你的小程序名、简介、每套测试的详情页文案，应该按这张词表重写。

**结论 3：另一类卖的是"配对/关系"，你一套都没有。**
城市适配、理想型、情侣匹配——都是**关系向**。这正好印证上一轮的选型判断（依恋类型 + 情侣契合度）。**这不是巧合，是市场已经替你验过一遍了。**

## 二、必须撤回的旧方案（合规红线）

《站外切片实验计划》2.2 节写的"小红书简介里写小程序名 + 评论统一回'简介里搜名字'"——**这个做法现在违规**。

已核实：
- 小红书 2025-03-12 生效新规，明确禁止**引导站外交易/引流**，违规形态包括留联系方式、评论区引流、发链接；处罚为警告、限流、**个人号封号**（商家扣积分）。
- 合规外跳能力（笔记挂组件、私信跳转卡片）**要求企业号/专业号**，在专业号后台"获客工具"开通，**个人号挂不了**。

叠加你自己定的**身份隔离**要求：马甲号 + 站外引流 + 可能被封 = 风险不对等。不值得。

## 三、修正后的路线

### 3.1 小红书降级为"验需求 + 慢品牌"，不再指望它拉新增

诚实的转化预期：小红书笔记 → 看到"人格测试树" → 切到微信 → 搜一搜 → 打开小程序。**跨 App 漏斗每掉一层剩 10~20%，全链路能走完的人通常不到 2%。** 1 万阅读 ≈ 一两百次打开，且你无法归因。

所以它的正确用法是**不导流**：
- **只把小红书当搜索面**（它已经是年轻人的决策搜索引擎）。发"27 种人格图鉴"这类**纯内容、无引导**的笔记，让人记住名字。
- 转化不靠引导，靠**品牌词自然回流**。慢、不可测，但零违规风险。
- 同时它仍然是**动因验证器**——评论区有没有人自己问"这是什么测试"，这个信号依然有效，只是**不要主动回答"去哪测"**。

### 3.2 新增一条主线：微信搜一搜关键词卡位（零成本、本周可做）

这条比小红书引流的确定性高一个数量级，因为**它就是用户已经在找你的那个动作**：

1. **小程序简介重写**，覆盖词表：MBTI / 16型人格 / 九型人格 / 大五人格 / i人e人 / 免费 / 中文。现在只有一句"基于心理学理论的人格测试小程序"，等于放弃了全部搜索面。
2. **每套测试一个可被索引的详情页**：详情页文案改成自然语言长描述（含搜索词），导航栏标题动态设置（现在 5 个页面的 `navigationBarTitleText` 是"测试详情""答题"这种废词，完全没有关键词价值）。
3. **sitemap 补 params**，让 `test-detail?id=mbti` 这类页面能被分别索引。
4. **名称**：「人格测试树」是好名字（有品类词 + 有意象），保留。但简介和页面标题要补齐长尾。

### 3.3 修正"暂不做变现"的判断

**付费深度报告不是变现手段，它就是被验证过的产品本体**（¥1.98 × 5 万单摆在那）。而且它顺手解决你两个空白：

- **晒的东西**：现在结果页一张图 + 一段话，深度报告（雷达图 + 各维度百分位 + 长解读 + 配对关系）才是值得存图发朋友圈的东西。
- **回来的理由**：免费轻测试当入口，深度报告当资产。

**但仍不建议现在就收费**。顺序应该是：
1. 先把深度报告**做出来免费送**，用它验证"用户看完愿不愿意晒"（`share_tap ÷ result_view` 会告诉你）。
2. 分享率证明它成立之后，再决定是收费、还是继续当免费钩子换增长。
3. 到那一步，"要不要云开发"就不再是架构讨论，而是"这份报告值不值得"的具体讨论。

## 五、目标已锁定（2026-10-12）

**用户拍板：未来三个月唯一目标是「小程序用户增长」，不是收入。**

由此产生的硬约束，后续所有讨论都要遵守：

- **变现相关全部关闭**，包括：小红书开店卖虚拟品、淘宝转卖、小程序内付费报告。不再作为方案提出。
- **不走任何信息差套利路线。** 淘宝那张图只保留一个产出：被付费验证过的**关键词表**，用于微信搜一搜卡位。
- 已核实的事实（用于以后快速否掉同类提议）：
  - 小红书官方类目以实物为主，**无标准虚拟商品入口**，虚拟品需报白或套服务类目，严禁直接上架数字内容；2026-02 起虚拟资料类目审核收紧（PPT 模板/课件/头像首批受限）。
  - 市面上通行的"合规解法"是**内容引流到站外交付**，而这正是小红书 2025-03-12 新规明令禁止、可封个人号的行为。即该路线唯一的走法本身违规。
  - **微信支付个人主体开不了**；淘宝店同样需要营业执照。"卖报告"无论走哪条路，第一道门都是经营主体，这是 yes/no 事实。
  - 收费会与自己写下的"非诊断工具、结果仅供参考"免责声明冲突，且心理测评类目普遍要求资质。
- **变现的合法后路仍然存在**（只是现在不做）：深度报告先在小程序内**免费送**，用它验证分享率；若成立且届时要收费，再办个体工商户。顺序不可颠倒。
