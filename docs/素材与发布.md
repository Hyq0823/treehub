# 云端美术与发布

环境：`cloud1-d2ghbskq3663254ce`。九套主题场景为独立透明 WebP，另有 `companions.webp`（3 列 × 6 行、18 位伙伴透明精灵图）；源图放在仓库外的 `treehub-cloud-assets/themes/v1/`，不打进小程序主包或分包。小程序只保存十个云文件 ID 和短期内存 URL。微信加载图片时仍可能使用设备临时缓存，不能承诺完全不产生临时缓存。

## 上传美术

运行素材检查，不需要云凭据，也不会发起上传：

```sh
node scripts/upload-theme-assets.cjs --source ../treehub-cloud-assets --dry-run
```

有云开发管理员凭据时，在仓库外安装管理端 SDK。凭据只通过当前管理员终端的环境变量提供，不写入项目、小程序代码、截图或聊天：

```sh
npm install --prefix ../treehub-cloud-admin @cloudbase/node-sdk
node scripts/upload-theme-assets.cjs --source ../treehub-cloud-assets --sdk-root ../treehub-cloud-admin
```

上传工具读取 `CLOUDBASE_SECRET_ID`、`CLOUDBASE_SECRET_KEY`，可选临时凭据的 `CLOUDBASE_SESSION_TOKEN`。管理员应给素材目录所需的最小上传权限。工具逐张上传到 `themes/v1/{themeId}.webp`，全部成功后才更新 `config/theme-assets.js`，并将实际 fileID 存为素材目录中的 `cloud-manifest.json`。不要把管理端 SDK 安装到小程序源码目录。

也可直接使用已登录的微信云开发控制台，上传九个主题与一张伙伴精灵图共十个 WebP 到 `themes/v1/`；复制每张文件的实际 fileID，创建以下 JSON（不要用示例代替真实 fileID）：

```json
{
  "environmentId": "cloud1-d2ghbskq3663254ce",
  "files": {
    "adventurer": "",
    "moon": "",
    "romantic": "",
    "dreamer": "",
    "wanderer": "",
    "listener": "",
    "collector": "",
    "observer": "",
    "aurora": "",
    "companions": ""
  }
}
```

```sh
node scripts/upload-theme-assets.cjs --import-manifest ../cloud-manifest.json
```

素材是可公开预览的品牌美术，允许客户端读取；禁止客户端写入、覆盖或删除。隐藏主题的“发现/使用”由主题权益控制，不能把公共图片地址当作保密或付费内容保护。数据集合继续禁止客户端直接读写，不要把公共素材权限套用到测评数据库。

没有素材配置或断网时显示轻量占位树，保留本地测评、收藏和记录功能；不要把占位树当成最终美术验收。

## 配置与部署

1. 上传主题与伙伴精灵图并重新编译，确认十个真实 fileID 均可读取。
2. 填写 `config/privacy.js` 的真实运营主体与联系邮箱。政策版本修改后，旧授权不自动沿用。
3. 按 `cloudfunctions/README.md` 部署云函数与集合权限、索引；旧版自动同步客户端应停止使用，避免绕过新的同意流程。
4. 微信后台完成实际业务对应的类目、简介、隐私保护指引、激励广告位配置和小程序备案信息。前端文档不能代替这些后台提交。
5. 在开发者工具选择当前稳定基础库并用真机检查：平台隐私授权、拒绝后本地测评、完整/中途关闭广告、切换菜单、恢复权益、导出/删除、海报生成。当前源码对较新 API 做能力检测。
6. 执行配置检查和回归：

```sh
node scripts/check-release.cjs
node --test tests/*.test.cjs
```

`check-release` 在 fileID 或运营主体未补齐时有意失败；它只检查静态配置，不能证明云函数已部署、数据库权限已生效、平台审核或备案已完成。

## 广告与权益

- 首次有效测评可免费选择一套基础主题。普通主题完整观看一次激励视频后，解锁当前这一套主题与两个伙伴。
- 隐藏主题需要完成五类不同测试才能发现；发现后仍需用户明确选择观看视频解锁。
- 深度报告的激励视频只解锁本次测评记录，与主题权益分开。复测的新报告独立解锁。
- 不使用“转发多少人才能解锁”等强制分享；邀请与海报用于自愿展示。
- 当前奖励由微信客户端 `onClose` 的完整观看结果驱动，云端校验归属、白名单、前置探索和重复写入。客户端事件并非防篡改的服务端观看证明，不应宣称具备支付级反作弊能力。以后若引入实际付费权益，需另行接入与平台能力相符的可靠服务端核验。
