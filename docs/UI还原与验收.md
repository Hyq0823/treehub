# UI 还原与验收

本轮以 `人格测试树高保真原型/第三轮_树与伙伴_九主题` 为视觉基准，优先还原女性向小红书受众需要的蓝色云朵、通透树世界、伙伴陪伴感与可截图报告。原型中的手机模型、手写英文字体和平台状态栏属于展示板包装，不直接进入微信页面。

- 来源：[taste-skill](https://github.com/Leonxlnx/taste-skill)，实际技能名称为 `design-taste-frontend`；仓库中没有名为 `wechat-miniprogram-ui-plugin` 的技能。
- 使用提交：`12af471f627f866411b4bd785b19646d3672784c`。
- 方向生成：`editorial-greeting`，seed `1117566569`。保留了真实题目、原生 WXML/WXSS 技术栈和既有主题素材，没有迁移前端框架。
- 已确认的蓝色渐变、柔和阴影与高光按钮是品牌画面的一部分，因此在技能审查中作为明确例外保留；几何溢出、破图、触控尺寸、正文可读性和页面标题不在例外范围。

## 还原重点

- 探索大厅：大场景欢迎区、当前主题入口、六项真实测试、进度与奖励反馈，底部使用原生自定义三栏导航。
- 我的树：主题画面成为首屏主角；主题图鉴改为横向收藏带；伙伴、历史和主题选择器保留在同一资产页面；隐藏主题不提前请求图片。
- 答题页：按真实的 2、3、5 选项分别布局，当前主题只作为低干扰背景；原始答案仍默认保留在本机。
- 深度报告：结果头图、主题伙伴、维度图表和三段深度内容分屏呈现，便于手机截图；广告解锁逻辑未因视觉改版而改变。

## 自动验收

`scripts/preview-ui.cjs` 从真实 WXML/WXSS、页面控制器、题库与本地测试记录生成浏览器辅助预览。主题素材只注入预览文件，不写入生产云配置。

```bash
node scripts/preview-ui.cjs --out /workspace/treehub-review/fidelity/after
```

已检查 360、390、430 三档手机宽度：无横向溢出、无破图，主要操作区域不小于 44px。`taste-skill inspect --app` 的大厅与我的树结构检查均为 0 FAIL；蓝色渐变、高光按钮和轻阴影按上面的品牌例外登记。外部验收产物位于 `/workspace/treehub-review/fidelity/`，其中 `before/` 是改版前，`after/` 与 `taste-final-*` 是本轮结果。

该预览不能代替微信开发者工具：激励视频、云文件临时地址、微信隐私授权、Canvas 海报导出和真机安全区仍需在微信环境中验收。生产页面目前会在云素材 ID 为空时显示可重试占位；上传 9 套主题和伙伴图集并导入真实 `cloud://` ID 后，才会显示与验收图相同的完整画面。
