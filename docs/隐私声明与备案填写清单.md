# 隐私声明与备案填写清单

## 是否必须收集用户答案到云端

不是。当前题库的评分、报告、主题推荐、成长与复测都可在本机完成，逐题答案始终不上传。微信隐私授权通过后默认使用当前微信账号备份结果摘要与权益；拒绝授权或主动关闭后继续使用本机模式，仍可完成测试、看基础报告、观看自愿解锁视频和收藏主题。

测评结果即使不用于诊断，也可能反映个人性格或心理倾向。运营者应按实际处理目的、影响与适用法规评估是否涉及敏感个人信息，不能因为叫“趣味测试”就免除隐私义务。

| 数据 | 本机 | 授权后的默认云备份 | 用途 |
| --- | --- | --- | --- |
| 逐题选项及规范题号 | 保存 | **不上传** | 本机记录、核对和未来评分兼容 |
| 测试/评分版本、维度分数、结果类型、完成时间、记录 ID | 保存 | 保存 | 恢复历史报告、复测与不同测试探索数 |
| 树种子 | 保存 | 保存 | 同账号恢复一致外观细节 |
| 旧树形快照 | 保存 | **不上传** | 原设备保留当时意象；新设备可用摘要还原并标注 |
| 主题 ID、获得来源/时间、当前主题 | 保存 | 保存 | 恢复用户已解锁主题 |
| 当前报告解锁时间 | 保存 | 保存 | 恢复该次深度报告权益 |
| OpenID | 微信平台提供 | 云函数识别本人、隔离访问 | 不能展示或发给其他用户；仍按个人信息管理 |
| 备份同意版本/时间、授权标记 | 保存 | 保存最小授权记录 | 证明选择、撤回后阻止旧设备重传 |
| 产品流程事件 | 本机最多 300 条 | **不上传** | 调试；不记录答案、分数或结果类型 |
| 姓名、头像昵称、手机号、身份证、通讯录、位置、性别、生日 | 不主动收集 | 不保存 | 当前产品没有必要性 |

对云端数据，公开分享与搜索均不得包含私人记录 ID、答案、分数、OpenID。主题名、意象插画和测试 ID 才是公开分享内容。

## 应用内已经提供的选择

- 原生微信隐私授权通过后默认开启结果摘要备份；拒绝授权或旧微信不支持时继续本机模式。
- 用户主动关闭后停止上传和拉取，后续启动不会自动重新开启。
- 应用内不再展示导出与删除操作区；后台接口保留现有账号隔离和删除防重传能力，供后续按真实运营流程接入。

## 微信后台《用户隐私保护指引》填写参考

以下是业务事实与用途参考，运营者需在实际后台选择相符字段，不能把文档当作已经提交。后台字段、适用权限和审核要求以微信当前页面为准。

| 声明内容 | 应与实现一致的写法 |
| --- | --- |
| 运营主体、联系方式 | 填写真实主体全称、用户权利联系邮箱或电话，且同步至 `config/privacy.js` |
| 用户主动填写的测评信息 | 逐题选项仅在本机用于生成报告；微信隐私授权后默认只备份结果摘要 |
| 微信账号标识 | 通过微信云开发识别当前用户，隔离本人历史与已解锁权益，不做公开展示 |
| 使用目的 | 提供测评、结果解读、用户主动选择的跨设备恢复、主题收藏与权益恢复 |
| 第三方服务 | 微信云开发用于静态图片和账号隔离的结果摘要备份；微信激励广告用于用户主动解锁主题或某次报告 |
| 广告信息 | 不向广告服务主动传递答题选项、分数或人格结果；平台自身信息处理需按其指引披露 |
| 相册与文件 | 当前只生成临时海报并打开微信预览，不主动申请相册写入 |
| 保存期限 | 备份开启期间用于本人恢复；用户可关闭后续同步，服务商备份及法定保留按实际政策处理 |
| 查阅与撤回 | 应用内「档案 → 隐私与数据管理」及真实运营者联系方式 |

云环境地域、服务商实际子处理安排、后台日志与备份保留时间需要运营者在微信云开发控制台核实，并据实补充；不要写未经确认的境内地域或“绝不收集任何信息”。

## 与备案的区别

应用内隐私政策、微信后台《用户隐私保护指引》、小程序备案是三项不同工作。前两项披露个人信息处理并支持用户权利；小程序备案需运营者在微信公众平台按实际主体与服务完成。若另行使用网站或独立域名，还需根据实际接入方式核对域名/网站备案与合法域名配置。不能仅在协议中写“已备案”就认为完成。

本轮未登录运营者微信账号，不能代填真实身份、提交后台声明、完成备案或声称审核通过。正式发布前使用 `node scripts/check-release.cjs` 检查素材与主体配置，并核对平台后台，保留提交和审核记录。
