# 微信云开发部署

云环境：`cloud1-d2ghbskq3663254ce`

1. 在微信开发者工具打开“云开发”，确认当前环境为上面的环境 ID。
2. 在数据库中创建 `treehub_users` 和 `treehub_assessments` 两个集合。
3. 将两个集合的客户端权限设为“所有用户不可读写”。小程序只通过云函数访问，云函数会按 OpenID 隔离用户。
4. 右键 `cloudfunctions/treehub-api`，选择“上传并部署：云端安装依赖”。
5. 在 `treehub_assessments` 创建组合索引：`owner` 升序、`completedAt` 降序。

当前云函数使用 `db.runTransaction`，部署时需使用支持事务的 `wx-server-sdk`。根据账号档案数量，将函数执行超时配置为合理值（建议先以 60 秒真机验证）；删除是按本人分批处理，若超时或离线，前端明确显示待删除，可继续重试，不会假装成功。

新版默认不备份；`authorizeBackup` 建立当前政策版本的设备授权，随后 `syncArchive` 才允许读取或推送。只保存结果摘要、种子与权益，原始 `answers` 和 `treeSnapshot` 不上传。已有旧数据库记录在用户授权后的拉取过程中分批清除旧原始字段；导出始终使用结果白名单。

`deleteMyData` 先撤回旧设备授权、与推送共用用户文档事务锁，再删除本人结果和主题，防止旧请求在删除后恢复记录。保留最小撤回哈希及删除时间标记，不保留 OpenID 明文、分数、答案、种子或主题。旧客户端没有新授权时将收到错误，应停止发布旧版自动同步代码。

云素材公开只读，测评数据库仍禁止客户端直读写，两种资源不要共用权限。素材上传见 [`../docs/素材与发布.md`](../docs/素材与发布.md)。隐私运营主体和邮箱/电话必须填写真实信息后发布，后台《用户隐私保护指引》及备案由运营者实际提交。

发布前使用两个微信账号分别完成测评，确认各自只能取回自己的档案；然后在同一微信账号的两台设备上确认历史、树种和 VIP 解锁状态能够合并。
